# @text2sql/frontend

Next.js frontend application for the Text-to-SQL interface.

## Status

🚧 **Under Development** - This package will be implemented in Phase 4 of the TypeScript migration.

## Planned Features

- **Next.js 14**: React framework with App Router
- **Server Components**: Optimized rendering strategy
- **AI Provider Selector**: Choose between OpenAI, Anthropic, or custom providers
- **Real-time Query Results**: Interactive data tables with export capabilities
- **Responsive Design**: Mobile-first UI with Tailwind CSS
- **Dark Mode**: Theme switching support

## Development

This package is currently a placeholder. Implementation will begin in Phase 4.1 (Issue #28).

- `@text2sql/shared`: Shared types and utilities
